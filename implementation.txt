PHASE 5 — Food Recognition & Quantity Estimation  [PARTIAL]
══════════════════════════════════════════════════════════════════════════════

Objective (from roadmap)
Identify foods, estimate consumption, calculate nutrition, log food diary per meal.

What is DONE
------------
[DONE] Local-first food pipeline (services/local_food_detector.py, services/food.py)
       - Full-frame canvas JPEG; child + food anywhere in view
       - Primary: models/food/food_detector.pt (+ optional COCO yolov8m fallback)
       - Non-blocking emit: UI gets _state 2 before nutrition/diary/allergen follow-up
       - Clarifai credit-saving gate (local confident → skip; empty → skip or person-mode;
         miss cache for repeated failures) — FOOD_PROVIDER=auto default
[DONE] WebSocket food UI (_state 2): food_list, food_main, boxes, food_cleared
[DONE] Structured nutrition to UI (_state 5): nutrition.py + nutrition_local.py + nutrition_score.js
[DONE] Legacy food_events + normalized food_diary_entries + meal_sessions (domain_writes)
[DONE] Meal start / end / duration_seconds on stop
[DONE] Quantity fields on diary (estimated_*_percent) via confidence_proxy_v1
[DONE] Demo foods work locally (banana, carrot, pizza, apple, orange, donut) with known gaps
       until custom model retrained on larger dataset

What is NOT DONE (Phase 5 / 5.1 exit criteria)
------------------------------------------------
[ ] Retrain / replace food_detector.pt on larger dataset (client priority — fixes missed labels)
[ ] Foodvisor API cross-reference (FOODVISOR_* in config; not wired in food.py)
[ ] Vision-language model fallback for low-confidence foods
[ ] Image-based quantity estimation (start vs end plate snapshots / CV area comparison)
      Current: confidence_proxy_v1 only — not plate comparison per roadmap
[ ] Meal start/end frame snapshots stored in MongoDB (Chill-baby had canvas snapshots)
[ ] Expand nutrition_lookup.json for all YOLO label set

Verdict
-------
Phase 5 **demo path is complete**. Remaining items are **Phase 5.1** — defer until after
Phase 8 unless product requires plate quantity or Foodvisor before profiles ship.
